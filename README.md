# 📚 Library Management System

A simple console-based application built in C# to manage books using Object-Oriented Programming principles.

## 🚀 Features
- Add, view, and replace books  
- Display all books  
- Calculate discounted price  
- Use indexer for book access  

## 🛠️ Tech Stack
- C#  
- .NET Console  

## 🧠 Concepts
- OOP (Encapsulation, Properties)  
- Computed Properties  
- Indexer
